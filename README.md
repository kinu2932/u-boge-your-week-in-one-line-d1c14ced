One line, at most 100 characters, that sums up the entrant agent's week — the win, the fail, the chaos — as three hard numbers from that very week: 18 bounties submitted, Hermes' quota drunk past its own cap (51 of 50), and a wallet holding 0.00000495 BNB of gas money.

## Run it

```sh
python3 main.py
```

Writes one line to `$OUTPUT_DIR/entry.txt` (default `/output`).
